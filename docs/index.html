JAHIDS.AI Agent Setup

OpenClaw + Hermes Agent + NVIDIA NIM · Built by Jahid

Provider terms can change.

Pricing, free-tier access, rate limits, model names, and licensing are set by the provider. Check your NVIDIA account and current terms. No paid fallback is configured by default.

Install

chmod +x scripts/*.sh
./scripts/setup.sh

The installer uses $HOME/tools/node24, $HOME/openclaw-state, and $HOME/.hermes.

Provider credentials

Read the key without putting it in shell history:

read -rsp "NVIDIA API key: " NVIDIA_API_KEY
echo
export NVIDIA_API_KEY
./scripts/run-openclaw.sh
# Or:
./scripts/run-hermes.sh

Never commit provider credentials or paste them into issues, screenshots, or chat. Revoke and replace an exposed key.

Optional JAHIDS mission API

  • Uses a separate owner-held JAHIDS_API_TOKEN.
  • Every mission endpoint requires Authorization: Bearer <token>.
  • Only /healthz is public and it returns liveness only.
  • Autonomy defaults to 0; high-impact categories are blocked.
  • The service binds to loopback. Do not expose it directly to the internet.

Read Authentication and Ownership and Runtime operations.

Verify

./scripts/setup.sh --verify
bash -n scripts/setup.sh scripts/run-openclaw.sh scripts/run-hermes.sh
cd runtime
PYTHONPATH=. python -m unittest discover -s tests -v

Scope

This repository provides agent setup and an early local integration runtime. It is not the full JAHIDS.AI Control Plane and does not provide multi-user OIDC, RBAC, or tenant isolation. Production deployment needs a reviewed identity provider, TLS, network controls, durable workers, audit records, managed secrets, backups, and independent security review.
